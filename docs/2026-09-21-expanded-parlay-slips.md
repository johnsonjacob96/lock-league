# Expanded sportsbook slips and game totals

The expanded slip format repeats a truncated summary above the actual legs and adds rewards, boosted odds, protection shields and a cash-out footer. The importer now reads detailed legs below the matchup, ignores the surrounding UI, and recognizes the displayed boosted odds when the header is unambiguous. It never calculates odds from a boost percentage. Ambiguous odds stay editable and flagged for review.

Real OCR on the saved Detroit/Buffalo crop reproduced protection shields as ©/® after names, merging Sam LaPorta and Josh Allen anytime-TD legs into neighboring picks. The name parser strips those trailing graphic fragments. Regression tests cover the actual image crop, its actual OCR text, and a representative expanded header/footer around that crop.

Both real-image tests read eight correct legs: Moore Over63.5 receiving yards; game Under54.5; LaPorta anytimeTD; Allen Over31.5 rushing yards; Moore Over4.5 receptions; St.Brown Over7.5 receptions; Allen anytimeTD; Gibbs Over30.5 receiving yards. Expanded header recognition yields +38132 when both prices are legible. If only one price is recognized on a boosted slip, odds stay blank with a review warning; the old unboosted price must never be silently chosen. Low-confidence name/icon text retains a review prompt; number-word confidence independently protects thresholds. LaPorta retains a low-confidence review prompt while its fields are correct. The full original uncropped image was supplied in chat; the automated full-format image uses the saved real crop with a representative reconstructed header/footer.

Parlay editing now offers **Game total points (Over/Under)**. It uses the slip's selected matchup and needs no player name. The API validates its direction/threshold, uses the combined scoreboard score for live progress, and only settles on final game status. Whole-number equality is a push; unavailable scores stay pending. Player props still require final player statistics. Manual overrides, member assignments, optimistic edits and Hall of Shame calculations are preserved. No schema, extra vendor requests, or changes to existing slips.

Validation: 172 backend tests; mobile/desktop upload, boosted-odds propagation, game-total selection and saving checks; real Tesseract recognition on the saved crop and expanded fixture. Existing standard/tall/logo OCR tests are included in the optional GitHub workflow OCR run. CDN assets were served locally for the local OCR test after intermittent browser/CDN loading failures; recognition used the same Tesseract version as production. New optional `ocr` workflow-dispatch input runs the network-dependent image tests without making normal CI depend on the CDN.
